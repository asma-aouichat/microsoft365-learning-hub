COURS 04

Références

Créer et gérer une table des matières, une table des illustrations, des notes, des citations, des sources et une bibliographie dans Microsoft Word.

Objectifs d’apprentissage

L’onglet Références regroupe les outils qui permettent d’organiser un document long et de documenter ses sources. Ces fonctions sont particulièrement utiles pour les rapports, travaux scolaires, mémoires, guides et documents professionnels.

À la fin du cours, vous serez capable de :
  • structurer un document avec les styles de titres ;
  • insérer et personnaliser une table des matières automatique ;
  • choisir le nombre de niveaux affichés et les caractères de suite ;
  • mettre à jour une table après modification du document ;
  • ajouter des légendes et produire une table des illustrations ;
  • insérer des notes de bas de page ;
  • créer, réutiliser et modifier des sources et citations ;
  • générer une bibliographie.
Principe essentiel : Word construit automatiquement plusieurs éléments de référence à partir de la structure du document. Une bonne utilisation des styles Titre 1, Titre 2, Titre 3 est donc la base d’une table des matières fiable.

1. Table des matières

Une table des matières présente les grandes parties du document et leurs numéros de page. Dans un document numérique, elle peut également faciliter la navigation vers les différentes sections.

1.1 Préparer le document

Avant de créer la table, appliquez les styles de titre aux éléments qui doivent apparaître dans la hiérarchie :

StyleUtilisationExemple
Titre 1Parties ou chapitres principauxChapitre 1 : Introduction
Titre 2Sous-parties1.1 Contexte
Titre 3Niveau inférieur1.1.1 Objectifs
À retenir : augmenter simplement la taille ou mettre un texte en gras ne suffit pas. Pour une table automatique, il faut utiliser les styles de titres ou configurer explicitement les niveaux à inclure.

2. Créer et personnaliser la table des matières

2.1 Insérer une table automatique

  1. Placez le curseur à l’endroit où la table doit apparaître, généralement après la page de garde.
  2. Ouvrez l’onglet Références.
  3. Cliquez sur Table des matières.
  4. Choisissez une table automatique ou une table personnalisée.

2.2 Personnaliser l’affichage

La boîte de dialogue de personnalisation permet de contrôler l’apparence et le niveau de détail de la table.

  • Afficher les numéros de page : affiche ou masque la page associée à chaque titre.
  • Aligner les numéros de page à droite : aligne les numéros sur le bord droit.
  • Caractères de suite : ajoute par exemple des points entre le titre et le numéro.
  • Afficher les niveaux : détermine la profondeur de la table.
  • Utiliser des liens hypertexte : permet une navigation directe dans le document lorsque cette option est disponible.

2.3 Associer les styles aux niveaux

Le bouton Options permet de préciser quels styles alimentent chaque niveau de la table.

Exemple : pour une table courte, affichez seulement deux niveaux. Pour un rapport détaillé, trois niveaux peuvent être utiles, à condition que la structure reste lisible.

3. Mettre à jour la table des matières

Lorsque le texte, les titres ou la pagination changent, la table doit être mise à jour afin de refléter la nouvelle structure du document.

  1. Cliquez dans la table des matières.
  2. Choisissez la commande de mise à jour de la table.
  3. Si seuls les déplacements de pages ont changé, mettez à jour les numéros de page.
  4. Si des titres ont été ajoutés, supprimés ou modifiés, mettez à jour toute la table.

4. Table des illustrations

La table des illustrations répertorie automatiquement les figures, images, graphiques ou tableaux auxquels une légende Word a été associée. Voici la procédure complète, illustrée étape par étape.

3.1 Étape 1 — Sélectionner l’illustration

Cliquez sur l’image, le graphique ou l’objet auquel vous souhaitez attribuer une légende.

3.2 Étape 2 — Insérer une légende

Dans Références, groupe Légendes, cliquez sur Insérer une légende.

3.3 Étape 3 — Configurer la légende

Choisissez l’étiquette Figure, complétez le titre et sélectionnez la position. Word gère automatiquement le numéro.

Important : ne saisissez pas manuellement « Figure 1 » dans un paragraphe ordinaire. Utilisez Insérer une légende pour que Word puisse construire la table automatiquement.

3.4 Étape 4 — Légender toutes les illustrations

Répétez l’opération pour chaque objet qui doit apparaître dans la table.

3.5 Étape 5 — Insérer la table des illustrations

Placez le curseur à l’endroit souhaité puis choisissez Références → Table des illustrations (le libellé peut être « Insérer une table des illustrations » selon la version).

3.6 Étape 6 — Régler les options

Choisissez l’étiquette à répertorier, les numéros de page, leur alignement et les caractères de suite, puis validez.

3.7 Étape 7 — Vérifier le résultat

Word génère automatiquement la liste à partir des légendes du document.

3.8 Étape 8 — Mettre la table à jour

Après l’ajout, la suppression ou le déplacement d’une figure, actualisez la table.

Exercice rapide : insérez trois images, ajoutez trois légendes, générez la table des illustrations, ajoutez une quatrième image puis mettez la table à jour.

4.9 Exemple complet — Créer une table des graphiques

Word utilise le même mécanisme que pour une table des illustrations. Pour obtenir une table des graphiques, on attribue d’abord aux graphiques une légende portant l’étiquette personnalisée Graphique, puis on génère la table à partir de cette étiquette.

Étape 1 — Insérer l’image ou le graphique

Dans l’onglet Insertion, cliquez sur Images pour insérer le visuel dans le document.

Étape 2 — Insérer une légende

Sélectionnez le graphique, puis utilisez la commande Insérer une légende. La capture montre également cette commande dans le menu contextuel du graphique.

Étape 3 — Créer l’étiquette « Graphique »

Dans la boîte de dialogue Légende, cliquez sur Nouvelle étiquette…, saisissez Graphique, puis validez. Sélectionnez ensuite cette nouvelle étiquette dans la liste.

Étape 4 — Compléter la légende du graphique

Après le numéro généré par Word, ajoutez un titre descriptif. Exemple : Graphique 1 : heures de formation 2014-2019, puis cliquez sur OK.

Étape 5 — Insérer la table des graphiques

Une fois tous les graphiques légendés, placez le curseur à l’endroit où la liste doit apparaître. Ouvrez Références, cliquez sur Insérer une table des illustrations, puis choisissez Graphique dans le champ Légende. Validez avec OK.

Étape 6 — Vérifier la table obtenue

Word rassemble alors automatiquement les légendes portant l’étiquette Graphique et affiche leurs numéros de page.

À retenir : la commande reste « Table des illustrations » dans Word, mais le choix de l’étiquette Graphique permet de produire une liste réservée aux graphiques. Le même principe peut être utilisé avec d’autres étiquettes personnalisées.

5. Notes de bas de page et notes de fin

Les notes de bas de page permettent d’ajouter une précision, une référence ou un commentaire sans alourdir le texte principal. Word insère un appel de note en exposant dans le texte et place automatiquement le contenu de la note au bas de la page. Les notes de fin suivent le même principe, mais sont regroupées à la fin du document ou de la section.

5.1 Insérer une note de bas de page

  1. Placez le curseur immédiatement après le mot, la phrase ou l’idée à documenter.
  2. Ouvrez l’onglet Références.
  3. Cliquez sur Insérer une note de bas de page.
  4. Word ajoute automatiquement un numéro en exposant et déplace le curseur dans la zone de note au bas de la page.
  5. Saisissez la référence ou l’explication souhaitée.
Exemple présenté : après le nom « Platon », un appel de note 1 renvoie à la référence placée au bas de la page : « Platon, L. (2002). République… ».

5.2 Insérer une note de fin

Une note de fin est utile lorsque l’on souhaite regrouper les notes plutôt que de les afficher au bas de chaque page.

  1. Placez le curseur après le passage concerné.
  2. Dans l’onglet Références, choisissez la commande d’insertion d’une note de fin.
  3. Word crée l’appel de note et vous conduit à l’emplacement réservé aux notes de fin.
  4. Saisissez le texte de la note.

5.3 Personnaliser les notes

Word permet également d’adapter la présentation et l’organisation des notes. Utilisez les options du groupe Notes de bas de page pour accéder aux paramètres disponibles.

TypeEmplacementUtilisation
Note de bas de pageAu bas de la page concernéeRéférence ou précision que le lecteur doit pouvoir consulter immédiatement.
Note de finRegroupée à la finDocument comportant de nombreuses notes ou présentation plus épurée.
À retenir : utilisez la fonction de note de Word plutôt que de taper manuellement un numéro en exposant. Word assure ainsi la numérotation et le lien entre l’appel de note et son contenu.

6. Citations et sources

Word permet d’enregistrer les informations d’une source, d’insérer des citations dans le texte et de réutiliser ensuite ces données pour générer automatiquement une bibliographie. La procédure commence par le choix du style bibliographique.

6.1 Étape 1 — Choisir le style bibliographique

Ouvrez l’onglet Références. Dans le groupe Citations et bibliographie, ouvrez la liste Style puis choisissez le style demandé, par exemple APA. La liste peut aussi proposer d’autres styles selon la version de Word.

Important : choisissez le style demandé avant de finaliser les citations et la bibliographie afin de conserver une présentation cohérente.

6.2 Étape 2 — Ouvrir « Insérer une citation »

Placez le curseur à l’endroit du texte où la référence doit être insérée, puis cliquez sur Insérer une citation.

6.3 Étape 3 — Ajouter une nouvelle source

Dans le menu qui s’ouvre, choisissez Ajouter une nouvelle source…. Word ouvrira la boîte de dialogue permettant d’enregistrer les informations bibliographiques.

6.4 Étape 4 — Choisir le type de source

Dans Type de source, indiquez la nature du document : livre, section de livre, article de revue, article de périodique, actes de conférence, rapport, etc. Les champs affichés s’adaptent au type choisi.

6.5 Étape 5 — Renseigner les informations bibliographiques

Complétez les champs proposés par Word. Pour un livre, la capture montre notamment Auteur, Titre, Année, Ville et Éditeur. Cliquez ensuite sur OK.

6.6 Réutiliser une source

Après son enregistrement, la source peut être réutilisée depuis Insérer une citation sans ressaisir toutes ses informations. Les outils de gestion des sources permettent également de corriger ou compléter les références enregistrées.

Bon réflexe : vérifiez soigneusement le nom des auteurs, le titre, l’année et les autres champs avant de valider. La bibliographie sera construite à partir de ces informations.

7. Bibliographie

Une fois les sources enregistrées et les citations insérées, Word peut générer automatiquement la liste des références utilisées dans le document.

7.1 Étape 1 — Choisir l’emplacement

Placez le curseur à l’endroit où la bibliographie doit apparaître, généralement à la fin du document, puis ouvrez l’onglet Références.

7.2 Étape 2 — Ouvrir le menu Bibliographie

Cliquez sur Bibliographie. Word affiche une galerie proposant différents intitulés et présentations, notamment Bibliography, References ou Works Cited dans la version illustrée.

7.3 Étape 3 — Vérifier le résultat

Word insère la liste automatiquement à partir des sources enregistrées. Vérifiez le titre de la section, la présence des références attendues et la cohérence avec le style bibliographique sélectionné.

ÉlémentFonction
StyleDétermine la présentation bibliographique appliquée par Word.
SourceContient les informations enregistrées sur le document cité.
CitationInsère dans le texte un renvoi vers une source.
BibliographieProduit la liste des références à partir des sources enregistrées.
Mini-activité : choisissez le style APA, créez une source de type livre, insérez sa citation dans un paragraphe, ajoutez une deuxième source puis générez la bibliographie à la fin du document.

8. TP pratique — Références dans Microsoft Word

Dans ce TP, vous ne devez pas créer le contenu du document à partir de zéro. Un document Word brut est fourni. Votre travail consiste à télécharger ce document puis à appliquer les fonctionnalités étudiées dans le cours : styles de titres, table des matières, légendes, tables des illustrations et des graphiques, notes, citations et bibliographie.

Document de départ à télécharger

Téléchargez le fichier ci-dessous et travaillez directement dans cette copie. Le document contient déjà le texte, les sections, les données nécessaires aux graphiques, les informations des sources bibliographiques et les passages à utiliser pendant le TP.

Télécharger le document brut du TP (.docx)
Avant de commencer : ouvrez le document téléchargé et enregistrez immédiatement une copie sous le nom TP_References_Nom_Prenom.docx. Ne retapez pas le contenu. Votre objectif est de transformer le document brut en un document Word structuré et automatisé.

Exercice 1 — Structurer les titres du document

Objectif : préparer la structure nécessaire à la table des matières.

  1. Repérez les titres principaux déjà présents : Introduction, Technologies utilisées, Enjeux et limites, Données pour les graphiques, Sources à saisir dans Word, Passages à utiliser pour les citations, Textes pouvant recevoir des notes et Conclusion.
  2. Appliquez le style Titre 1 aux titres principaux pertinents du document.
  3. Repérez les sous-sections, notamment Intelligence artificielle, Plateformes d’apprentissage et Outils collaboratifs.
  4. Appliquez le style Titre 2 aux sous-sections.
  5. Vérifiez visuellement la hiérarchie des titres dans tout le document.

Question : pourquoi un titre simplement mis en gras n’est-il pas équivalent à un paragraphe auquel le style « Titre 1 » a été appliqué ?

Exercice 2 — Créer la table des matières

Objectif : générer automatiquement la structure du document.

  1. Insérez une nouvelle page après la page de présentation.
  2. Placez le curseur sur cette page.
  3. Choisissez Références → Table des matières.
  4. Insérez une table des matières automatique.
  5. Vérifiez que les titres de niveau 1 et 2 apparaissent correctement avec leurs numéros de page.
  6. Modifiez ensuite un titre ou ajoutez un nouveau sous-titre dans le document.
  7. Revenez à la table des matières et choisissez Mettre à jour toute la table.

Exercice 3 — Insérer et légender des illustrations

Objectif : utiliser les légendes automatiques de Word. Les images ne sont pas imposées dans le document brut : choisissez trois images pertinentes en lien avec le thème du document et insérez-les aux endroits appropriés.

  1. Insérez au moins trois images dans les sections sur les technologies numériques.
  2. Sélectionnez la première image puis choisissez Références → Insérer une légende.
  3. Utilisez l’étiquette Figure.
  4. Ajoutez un titre descriptif après le numéro créé automatiquement par Word.
  5. Répétez l’opération pour les autres images.
  6. Vérifiez que Word produit automatiquement Figure 1, Figure 2, Figure 3.
Attention : ne saisissez pas manuellement les numéros des figures.

Exercice 4 — Créer la table des illustrations

  1. Insérez une nouvelle page après la table des matières ou à l’emplacement indiqué par l’enseignante.
  2. Ajoutez le titre Table des illustrations.
  3. Choisissez Références → Insérer une table des illustrations.
  4. Sélectionnez l’étiquette Figure.
  5. Affichez les numéros de page et conservez les caractères de suite.
  6. Validez et vérifiez que vos trois figures apparaissent.

Exercice 5 — Créer deux graphiques à partir des données fournies

Objectif : exploiter les deux tableaux déjà présents dans la section Données pour les graphiques.

  1. Utilisez les données du tableau Utilisation hebdomadaire des outils numériques pour créer un premier graphique.
  2. Utilisez les données du tableau Répartition des outils utilisés par les étudiants pour créer un deuxième graphique.
  3. Choisissez un type de graphique adapté à chaque série de données.
  4. Ajoutez un titre clair à chaque graphique.

Exercice 6 — Légender les graphiques et créer la table des graphiques

  1. Sélectionnez le premier graphique et ouvrez Insérer une légende.
  2. Cliquez sur Nouvelle étiquette… et créez l’étiquette Graphique.
  3. Ajoutez un titre descriptif après Graphique 1.
  4. Appliquez la même étiquette au deuxième graphique.
  5. Ajoutez une page intitulée Table des graphiques.
  6. Choisissez Références → Insérer une table des illustrations, puis sélectionnez l’étiquette Graphique.
  7. Validez et vérifiez que les deux graphiques apparaissent dans la liste.

Exercice 7 — Insérer des notes de bas de page et une note de fin

Utilisez la section Textes pouvant recevoir des notes du document brut. Elle contient les notions Apprentissage hybride, Collaboration synchrone et Littératie numérique.

  1. Choisissez deux de ces notions et repérez dans le document un emplacement pertinent pour les utiliser.
  2. Insérez une note de bas de page pour la première notion et placez sa définition dans la note.
  3. Insérez une deuxième note de bas de page pour une autre notion.
  4. Insérez ensuite une note de fin pour la troisième notion.
  5. Comparez l’emplacement d’une note de bas de page avec celui d’une note de fin.

Exercice 8 — Enregistrer les sources bibliographiques

Objectif : utiliser les informations déjà fournies dans la section Sources à saisir dans Word.

  1. Dans Références, choisissez le style APA.
  2. Choisissez Insérer une citation → Ajouter une nouvelle source.
  3. Créez la source Martin, Claire — Technologies numériques et apprentissage comme source de type Livre, en utilisant les informations fournies.
  4. Créez la source Bernard, Julien — Usages pédagogiques de l’intelligence artificielle comme Article de revue.
  5. Ajoutez également la source de Lefebvre, Nadia comme livre.
  6. Vérifiez les auteurs, titres, années et autres champs avant de valider.

Question : pourquoi les champs proposés par Word changent-ils lorsque vous passez de « Livre » à « Article de revue » ?

Exercice 9 — Insérer les citations dans le texte

Utilisez les trois textes de la section Passages à utiliser pour les citations comme matériel de travail.

  1. Associez le passage sur les outils numériques à une source pertinente enregistrée dans Word.
  2. Associez le passage sur l’intelligence artificielle à la source de Bernard.
  3. Associez le passage sur les environnements collaboratifs à la source de Lefebvre.
  4. Placez ces passages dans des sections pertinentes du document si nécessaire.
  5. À la fin de chaque passage, utilisez Insérer une citation pour ajouter la source correspondante.
  6. Vérifiez la présentation des citations avec le style APA.

Exercice 10 — Générer la bibliographie

  1. Placez le curseur à la fin du document.
  2. Insérez une nouvelle page.
  3. Choisissez Références → Bibliographie.
  4. Insérez une liste de références automatique.
  5. Vérifiez que les sources citées apparaissent dans la bibliographie.
  6. Si une information est incorrecte, corrigez la source dans Word plutôt que de modifier uniquement le texte affiché dans la bibliographie.

Exercice 11 — Mise à jour générale

Objectif : vérifier que les éléments automatiques restent cohérents après des modifications.

  1. Ajoutez une nouvelle sous-section avec le style Titre 2.
  2. Ajoutez une quatrième figure avec une légende automatique.
  3. Modifiez l’emplacement d’un graphique afin qu’il change de page.
  4. Mettez à jour la table des matières.
  5. Mettez à jour la table des illustrations.
  6. Mettez à jour la table des graphiques.
  7. Vérifiez la numérotation des figures, graphiques et notes.

Exercice 12 — Vérification et remise

Avant de remettre votre travail, assurez-vous que le document final contient :

  • une hiérarchie correcte avec les styles Titre 1 et Titre 2 ;
  • une table des matières automatique et à jour ;
  • au moins 4 figures avec des légendes automatiques ;
  • une table des illustrations ;
  • 2 graphiques créés à partir des données fournies ;
  • une table des graphiques ;
  • 2 notes de bas de page et 1 note de fin ;
  • 3 sources enregistrées dans Word ;
  • au moins 3 citations dans le texte ;
  • une bibliographie automatique.
