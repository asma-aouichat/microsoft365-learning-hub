COURS 05

Révision

Suivre, commenter, afficher, examiner, filtrer, accepter et refuser les modifications d’un document Microsoft Word.

Objectifs d’apprentissage

L’onglet Révision facilite la correction et le travail collaboratif. Grâce au Suivi des modifications, Word conserve une trace visible des changements afin que l’auteur du document puisse les examiner avant de décider de les accepter ou de les refuser.

À la fin du cours, vous serez capable de :
  • activer et désactiver le suivi des modifications ;
  • identifier les ajouts, suppressions et autres marques de révision ;
  • contrôler l’affichage des marques ;
  • parcourir les changements d’un document ;
  • accepter ou refuser une modification ;
  • filtrer les révisions par type ou par relecteur ;
  • ajouter, répondre, résoudre et supprimer des commentaires ;
  • finaliser un document après une séance de révision.
Principe essentiel : le suivi des modifications ne corrige pas automatiquement le document. Il enregistre les changements afin qu’ils puissent être examinés et validés.

1. Suivi des modifications

Le Suivi des modifications permet à Word de signaler les changements apportés au document. Lorsque cette fonction est active, les insertions et suppressions restent identifiables au lieu d’être intégrées silencieusement au texte.

1.1 Activer le suivi

  1. Ouvrez le document à réviser.
  2. Choisissez l’onglet Révision.
  3. Dans le groupe Suivi, cliquez sur Suivi des modifications.
  4. Modifiez ensuite le texte normalement.
  5. Observez la manière dont Word signale les changements.
Exemple
Les outils numériques remplacent totalement peuvent soutenir l’apprentissage lorsqu’ils sont utilisés de manière pertinente.

Dans cet exemple pédagogique, une expression a été supprimée et une autre a été insérée. Dans Word, la présentation exacte dépend du mode d’affichage choisi.

1.2 Désactiver le suivi

Lorsque vous cliquez de nouveau sur Suivi des modifications, Word cesse d’enregistrer les nouvelles modifications. Les marques déjà présentes ne disparaissent pas pour autant : elles doivent encore être acceptées ou refusées.

À retenir : désactiver le suivi n’est pas la même chose qu’accepter les modifications déjà enregistrées.

2. Afficher les marques

Word permet de contrôler la façon dont les révisions apparaissent à l’écran. Cela aide à lire un document très corrigé sans perdre la trace des changements.

2.1 Afficher ou masquer des types de marques

  1. Ouvrez Révision.
  2. Dans le groupe Suivi, ouvrez Afficher les marques.
  3. Choisissez les catégories de marques que vous souhaitez voir.
  4. Vérifiez le document après chaque changement d’affichage.
ÉlémentRôle pendant la révision
Insertions et suppressionsPermettent d’identifier le texte ajouté ou retiré.
Mise en formePermet d’identifier certains changements de présentation lorsque Word les suit.
Personnes / relecteursPermettent de concentrer l’affichage sur les changements de certains auteurs.

2.2 Affichage en ligne et autres présentations

Selon la version et les paramètres de Word, les révisions peuvent apparaître directement dans le texte ou être présentées de manière plus discrète. Le choix de l’affichage modifie surtout ce que vous voyez, et non la présence réelle des modifications enregistrées.

Attention : masquer une marque ne signifie pas la supprimer. Une modification masquée peut toujours faire partie du document et réapparaître lorsque l’affichage change.

3. Examiner les modifications

Lorsqu’un document contient plusieurs changements, il est préférable de les examiner méthodiquement plutôt que de parcourir le texte au hasard.

3.1 Parcourir les changements

  1. Placez-vous dans l’onglet Révision.
  2. Utilisez les commandes de navigation vers la modification précédente ou suivante.
  3. Lisez le passage complet avant de prendre une décision.
  4. Vérifiez si la modification améliore réellement le sens, la précision ou la présentation.
  5. Décidez ensuite de l’accepter ou de la refuser.
Exemple : un relecteur remplace « les technologies améliorent toujours l’apprentissage » par « les technologies peuvent améliorer l’apprentissage ». Avant d’accepter, vérifiez le contexte : la deuxième formulation est plus nuancée, mais la décision dépend de l’objectif du document.

4. Accepter ou refuser les modifications

Une révision reste provisoire tant qu’elle n’a pas été traitée. Accepter valide le changement ; Refuser revient à conserver ou restaurer la version antérieure correspondante.

4.1 Accepter une modification

  1. Sélectionnez ou placez-vous sur la modification.
  2. Dans Révision, utilisez la commande Accepter, ou utilisez le menu contextuel lorsque cette option est proposée.
  3. Vérifiez le résultat dans le texte.
  4. Passez à la modification suivante.

4.2 Refuser une modification

  1. Repérez la modification à ne pas conserver.
  2. Utilisez la commande Refuser.
  3. Word annule cette proposition de changement.
  4. Relisez la phrase obtenue pour vérifier sa cohérence.

4.3 Traiter plusieurs modifications

Word peut proposer des commandes permettant d’accepter ou de refuser plusieurs changements. Ces commandes sont pratiques à la fin d’une révision, mais elles doivent être utilisées avec prudence.

Bonne précaution : n’acceptez pas toutes les modifications en une seule opération avant d’avoir vérifié le document. Une modification peut être techniquement correcte mais inadaptée au sens voulu par l’auteur.
ActionRésultat
AccepterLa proposition devient partie intégrante du document.
RefuserLa proposition est rejetée et la version correspondante avant cette révision est conservée/restaurée.
MasquerChange uniquement l’affichage ; la révision n’est pas nécessairement traitée.

5. Filtrer les révisions

Dans un document collaboratif, de nombreuses modifications peuvent être présentes. Le filtrage permet de concentrer l’examen sur une catégorie de changements ou sur un relecteur précis.

5.1 Filtrer par type

Utilisez Révision → Suivi → Afficher les marques pour contrôler les catégories visibles. Vous pouvez, par exemple, vous concentrer sur les insertions et suppressions avant d’examiner d’autres changements.

5.2 Filtrer par relecteur

Lorsque plusieurs personnes ont participé à la révision, Word peut distinguer leurs interventions. L’affichage par personne permet d’examiner les changements d’un relecteur particulier.

Situation : trois personnes ont relu un rapport. Vous pouvez examiner d’abord les changements du responsable du contenu, puis ceux de la personne chargée de la révision linguistique, au lieu d’afficher toutes les interventions simultanément.
À retenir : le filtrage sert à faciliter l’examen. Il ne constitue pas, à lui seul, une acceptation ou un refus des changements.

6. Gestion des commentaires

Les commentaires permettent de poser une question, proposer une amélioration ou expliquer un point sans modifier directement le contenu du document. Ils sont particulièrement utiles lors d’une relecture collaborative.

Différence essentielle : le Suivi des modifications enregistre les changements effectués dans le texte, tandis qu’un commentaire ajoute une remarque associée à un passage sans remplacer ce passage.

6.1 Ajouter un commentaire

  1. Sélectionnez le mot, la phrase ou le passage concerné.
  2. Ouvrez l’onglet Révision.
  3. Cliquez sur Nouveau commentaire.
  4. Saisissez votre remarque dans la zone de commentaire.
  5. Publiez le commentaire si votre version de Word affiche un bouton de publication.
Exemple : sélectionnez une affirmation trop générale et ajoutez le commentaire : « Pouvez-vous ajouter une source ou préciser cette affirmation ? »

6.2 Répondre à un commentaire

Dans un travail collaboratif, un autre utilisateur peut répondre au commentaire afin de poursuivre la discussion sans modifier le texte principal. Utilisez la commande Répondre dans le fil du commentaire, puis saisissez votre réponse.

6.3 Parcourir et afficher les commentaires

Les commandes de l’onglet Révision permettent d’afficher les commentaires et de parcourir les remarques du document. Selon la version de Word, les commentaires peuvent apparaître dans la marge ou dans un volet dédié.

  1. Affichez les commentaires du document.
  2. Sélectionnez un commentaire pour identifier le passage auquel il est associé.
  3. Lisez le fil de discussion avant d’apporter une modification.
  4. Passez ensuite au commentaire suivant jusqu’à la fin du document.

6.4 Résoudre ou supprimer un commentaire

ActionQuand l’utiliser ?Effet
RépondreLorsqu’une discussion ou une précision est nécessaire.Ajoute une réponse au fil sans modifier le texte.
RésoudreLorsque la remarque a été traitée et que la discussion est terminée.Marque la discussion comme traitée, selon la version de Word.
SupprimerLorsque le commentaire n’a plus à être conservé.Retire le commentaire du document.
Attention : supprimer un commentaire n’accepte ni ne refuse une modification suivie. Les commentaires et les marques de révision sont deux éléments distincts et doivent être vérifiés séparément.

6.5 Commentaires et travail collaboratif

Utilisez les commentaires pour les questions, les demandes de clarification et les suggestions qui nécessitent une discussion. Utilisez le suivi des modifications lorsque vous souhaitez proposer directement une nouvelle formulation dans le document.

À retenir : avant de finaliser un document, vérifiez à la fois les modifications suivies et les commentaires encore présents.

7. Méthode complète de révision

Une procédure organisée réduit le risque de laisser des modifications non vérifiées dans le document final.

  1. Conserver une copie : gardez une version originale avant une révision importante.
  2. Activer le suivi : activez le Suivi des modifications avant de commencer les corrections.
  3. Réviser : corrigez le texte, supprimez les éléments inutiles et ajoutez les informations nécessaires.
  4. Contrôler l’affichage : choisissez les marques utiles pour votre étape de travail.
  5. Filtrer si nécessaire : examinez un type de changement ou un relecteur à la fois.
  6. Examiner : parcourez les modifications dans leur contexte.
  7. Décider : acceptez ou refusez chaque proposition.
  8. Vérifier : relisez le document final et assurez-vous que les marques restantes correspondent à votre intention.

8. Bonnes pratiques et erreurs à éviter

Bonne pratiquePourquoi ?
Activer le suivi avant de commencer une révision collaborative.Les changements restent identifiables.
Lire le contexte avant d’accepter.Une correction locale peut modifier le sens global.
Utiliser les filtres pour les documents très révisés.L’examen devient plus clair et méthodique.
Conserver une copie originale.Elle permet de revenir à l’état initial si nécessaire.
Effectuer une dernière vérification.Le document remis ne doit pas contenir de révisions involontaires.
Erreurs fréquentes :
  • croire qu’une marque masquée a été supprimée ;
  • désactiver le suivi et penser que les anciennes révisions sont automatiquement acceptées ;
  • accepter toutes les modifications sans les lire ;
  • modifier un document collaboratif sans activer le suivi alors qu’une trace des changements est nécessaire.

9. Activité pratique guidée

Objectif : réaliser un cycle complet de révision dans Word.

Texte de départ :

Les outils numériques sont utilisé dans plusieurs établissements. Ils remplace les méthodes traditionnelles et garantissent toujours de meilleurs résultats. Les étudiants utilise également des plateformes pour communiquer.

Travail demandé

  1. Copiez le texte dans un nouveau document Word et enregistrez-le sous le nom Revision_Nom_Prenom.docx.
  2. Activez Révision → Suivi des modifications.
  3. Corrigez les accords incorrects dans le texte.
  4. Remplacez la formulation absolue « garantissent toujours de meilleurs résultats » par une formulation plus nuancée.
  5. Ajoutez une phrase expliquant un avantage possible des plateformes numériques.
  6. Supprimez un mot ou une expression que vous jugez inutile et observez sa marque de révision.
  7. Ajoutez un commentaire sur une phrase pour demander une précision.
  8. Répondez au commentaire, puis marquez-le comme résolu ou supprimez-le après traitement.
  9. Utilisez Afficher les marques pour contrôler l’affichage des changements.
  10. Parcourez les modifications une à une.
  11. Acceptez au moins deux modifications.
  12. Refusez volontairement une autre modification afin d’observer le résultat.
  13. Vérifiez les marques restantes et finalisez le document.

Défi supplémentaire

Travaillez à deux sur une copie du document. Chaque personne effectue quelques changements avec le suivi actif. Utilisez ensuite le filtrage par relecteur pour examiner séparément les interventions.

Critères de réussite

  • ☐ Le suivi des modifications a été utilisé.
  • ☐ Le document contient plusieurs types de changements.
  • ☐ Au moins un commentaire a été ajouté et traité.
  • ☐ Les marques ont été affichées et contrôlées.
  • ☐ Les modifications ont été parcourues méthodiquement.
  • ☐ Au moins deux modifications ont été acceptées.
  • ☐ Au moins une modification a été refusée.
  • ☐ Le document final a été relu.
