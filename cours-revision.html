COURS 05

Révision

Suivre, afficher, accepter et refuser les modifications d’un document.

Suivi des modifications

Dans l’onglet Révision, le cours passe par Suivi puis Suivi des modifications. Les suppressions et ajouts sont signalés et les auteurs peuvent être distingués.

Afficher les marques

Révision > Suivi > Afficher les marques permet de contrôler l’affichage. Le support présente aussi l’affichage des révisions en ligne.

Accepter ou refuser

Une modification peut être acceptée ou refusée individuellement via le menu contextuel.

Filtrer les révisions

Le cours montre comment examiner les changements par type de modification ou par relecteur spécifique, puis accepter ou refuser les changements.

Activité pratique

Activez le suivi des modifications, modifiez un paragraphe, filtrez les marques par type puis acceptez une modification et refusez-en une autre.
