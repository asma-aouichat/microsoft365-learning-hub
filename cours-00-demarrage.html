00 • AVANT DE COMMENCER

À quoi sert Microsoft Word ?

Microsoft Word est un logiciel de traitement de texte. Il permet de créer, modifier, mettre en forme, enregistrer, imprimer et partager des documents : lettres, rapports, CV, travaux scolaires, comptes rendus et documents professionnels.

Word pour le web
Fonctionne dans un navigateur. Pratique pour travailler depuis plusieurs appareils et collaborer.
Application Word
Installée sur Windows ou macOS. Elle propose l’ensemble des outils de bureau, y compris certaines fonctions plus avancées.

Le même document .docx peut être ouvert dans Word pour le web ou dans l’application de bureau, mais certaines fonctions peuvent se comporter différemment.

02 • LANCER WORD

Ouvrir Microsoft Word

Windows

À retenir : le cours peut être suivi avec Word de bureau ou Word pour le web. Les boutons peuvent changer légèrement de place.

04 • OUVRIR UN FICHIER

Ouvrir un document Word existant

Un document Word porte généralement l’extension .docx. Plusieurs méthodes sont possibles.

Depuis Word

Fichier → Ouvrir, puis choisissez un document récent, OneDrive ou parcourez les dossiers de l’ordinateur.

Depuis Finder / Explorateur

Localisez le fichier .docx puis double-cliquez dessus. Word s’ouvre avec le document.

Depuis Word pour le web

Sur la page d’accueil, utilisez les fichiers récents ou l’option permettant de charger un fichier.

Depuis OneDrive

Localisez le document dans votre espace OneDrive puis ouvrez-le dans le navigateur ou l’application de bureau.

Problème fréquent : si le fichier téléchargé est encore dans Téléchargements, pensez à le déplacer dans votre dossier de cours avant de commencer.

06 • ENREGISTRER

Enregistrer sans perdre son travail

Document local

Utilisez Ctrl+S sous Windows ou ⌘+S sur Mac. Lors du premier enregistrement, choisissez le dossier et le nom du fichier.

Pour créer une autre version, utilisez Enregistrer sous ou Enregistrer une copie selon votre version.

OneDrive / SharePoint

Dans Microsoft 365, l’Enregistrement automatique peut sauvegarder les modifications automatiquement lorsque le fichier est stocké dans OneDrive ou SharePoint.

Vérifiez toujours le nom et l’emplacement du fichier.

Bonne pratique : utilisez des noms compréhensibles : TP00_Aouichat_Asma.docx est préférable à Document1.docx.

Créer une version PDF

Le fichier .docx reste le document de travail modifiable. Le .pdf est utile pour remettre ou partager une version dont la mise en page doit rester stable. Conservez le DOCX original lorsque vous exportez en PDF.

07 • ORGANISATION

Fermer, retrouver et rouvrir un document

Assurez-vous que le document est enregistré.
Fermez le document puis Word.
Rouvrez Word et regardez la liste des documents récents.
Si nécessaire, utilisez Ouvrir et parcourez OneDrive ou vos dossiers.
Vérifiez le nom du fichier avant de reprendre votre travail.
Si Word se ferme accidentellement : Word dispose aussi de fonctions de récupération. Pour les fichiers Microsoft 365 stockés dans OneDrive/SharePoint, l’enregistrement automatique et l’historique des versions apportent une protection supplémentaire.

09 • EXERCICE D’AUTONOMIE

À vous de jouer

Sans reprendre les étapes précédentes, créez un nouveau document nommé Exercice00_Nom_Prenom.docx. Saisissez un titre et deux paragraphes, enregistrez-le dans un dossier Cours Word, fermez Word, retrouvez le fichier, rouvrez-le et ajoutez la date du jour. Terminez en produisant une version PDF.

Afficher les points à vérifier
Auto-évaluation : le nom est correct; le DOCX est dans le bon dossier; le fichier peut être retrouvé après fermeture; la modification est enregistrée; le PDF existe sans remplacer le DOCX.
