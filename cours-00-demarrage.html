00 • AVANT DE COMMENCER

Microsoft 365 et Microsoft Word

Microsoft Word est l’application de traitement de texte de Microsoft 365. Elle permet de créer des lettres, rapports, CV, travaux scolaires et documents professionnels, puis de les enregistrer, imprimer, partager ou exporter en PDF.

Word pour le web
Utilisable directement dans un navigateur après connexion à Microsoft 365. Aucune installation locale de Word n’est nécessaire.
Application Word
Installée sur Windows ou macOS. Elle donne accès aux fonctions de bureau et permet aussi de travailler avec des fichiers locaux.
Important — licence : la possibilité d’installer les applications dépend du type de licence associé au compte. La documentation de l’Université de Lausanne signale notamment que certaines licences donnent uniquement accès à Microsoft 365 en ligne.
01 • CONNEXION

Étape 1 — Se connecter au portail Microsoft 365

Avant d’installer ou d’utiliser Word en ligne, connectez-vous au portail Microsoft avec le compte fourni par votre établissement ou votre organisation.

Ouvrez un navigateur : Edge, Chrome, Firefox ou Safari.
Accédez au portail Microsoft 365 puis choisissez Se connecter.
Saisissez votre adresse institutionnelle, professionnelle ou scolaire. Dans la référence UNIL, l’exemple utilisé est une adresse @unil.ch.
Cliquez sur Suivant, puis saisissez le mot de passe associé au compte.
Effectuez la vérification de sécurité ou l’authentification multifacteur si elle est demandée.

02 • INSTALLATION

Étape 2 — Télécharger et installer Microsoft 365

Après la connexion, recherchez l’option d’installation des applications. La documentation UNIL utilise le bouton « Installer Office ». Si ce bouton n’est pas disponible, votre licence peut être limitée aux applications en ligne.

Repère visuel de la référence : l’écran « Office apps & devices » montre le bouton Install Office. Voir la capture originale UNIL ↗

Windows

Cliquez sur Installer Office et téléchargez le programme d’installation.
Ouvrez le fichier téléchargé.
Si Windows affiche le contrôle de compte d’utilisateur, cliquez sur Oui.
Restez connecté à Internet pendant le téléchargement et l’installation des applications.
Lorsque le message indique que l’installation est terminée, cliquez sur Fermer.

Captures Windows originales : autorisation, installation et fin d’installation ↗

macOS

Cliquez sur Installer Office puis ouvrez le fichier d’installation téléchargé.
Dans l’assistant, cliquez sur Continuer.
Lisez les conditions, cliquez sur Continuer, puis sur Accepter.
Cliquez sur Installer.
Saisissez le mot de passe de votre session macOS si le système le demande, puis validez.
À la fin, cliquez sur Fermer. Vous pouvez ensuite déplacer l’installeur dans la corbeille.

03 • ACTIVATION

Étape 3 — Ouvrir Word et activer Microsoft 365

Après l’installation de Microsoft 365, ouvrez Word puis associez l’application à votre compte institutionnel. Les captures ci-dessous proviennent de la procédure Microsoft 365 du Centre informatique de l’Université de Lausanne (UNIL). L’apparence peut varier selon la version installée.

3.1 — Ouvrir Microsoft Word sous Windows

Cliquez sur le bouton Démarrer de Windows.
Recherchez Word dans la liste des applications ou dans la zone de recherche.
Cliquez sur Word pour lancer l’application.

3.2 — Confirmer le compte utilisé pour activer Office

Au premier démarrage, Office peut afficher un écran de bienvenue avec le compte détecté. Vérifiez l’adresse avant de continuer.

Vérifiez que l’adresse correspond à votre compte institutionnel ou professionnel.
Si le compte est correct, cliquez sur Continuer.
Sinon, choisissez Modifier le compte.

3.3 — Saisir ou confirmer l’adresse de connexion

Saisissez votre adresse institutionnelle.
Cliquez sur Suivant.
Si Microsoft le demande, utilisez le compte professionnel ou scolaire associé à votre établissement.

3.4 — Entrer le mot de passe

Saisissez le mot de passe du compte.
Cliquez sur Se connecter.
Effectuez l’authentification multifacteur si votre établissement la demande.

3.5 — Accepter le contrat de licence si cet écran apparaît

Selon la version installée, Office peut afficher un écran relatif au contrat de licence. Lisez les informations affichées avant de poursuivre.

Vérifiez les informations relatives au produit et à la licence.
Consultez le contrat si nécessaire.
Cliquez sur Accepter pour poursuivre lorsque vous êtes prêt à utiliser Office selon ces conditions.
À retenir : les captures UNIL utilisent prenom.nom@unil.ch. Dans ce cours, cette adresse représente simplement le compte Microsoft 365 fourni par votre établissement ou votre organisation.
04 • TROIS FAÇONS D’OUVRIR WORD

Étape 4 — Accéder à Microsoft Word

Windows

Démarrer → Word. Vous pouvez aussi épingler Word à la barre des tâches pour le retrouver plus rapidement.

macOS

Applications → Microsoft Word, ou utilisez Spotlight avec ⌘ + Espace puis recherchez « Word ».

Word pour le web

Connectez-vous au portail Microsoft 365 et sélectionnez Word parmi les applications disponibles.

Si vous ne pouvez pas installer Word : utilisez Word pour le web. C’est également une bonne solution sur un ordinateur où vous ne disposez pas des droits d’installation.

06 • OUVRIR UN FICHIER

Ouvrir un document Word existant

Un document Word porte généralement l’extension .docx. Plusieurs méthodes sont possibles.

Depuis Word

Fichier → Ouvrir, puis choisissez un document récent, OneDrive ou parcourez les dossiers de l’ordinateur.

Depuis Finder / Explorateur

Localisez le fichier .docx puis double-cliquez dessus. Word s’ouvre avec le document.

Depuis Word pour le web

Sur la page d’accueil, utilisez les fichiers récents ou l’option permettant de charger un fichier.

Depuis OneDrive

Localisez le document dans votre espace OneDrive puis ouvrez-le dans le navigateur ou l’application de bureau.

Problème fréquent : si le fichier téléchargé est encore dans Téléchargements, pensez à le déplacer dans votre dossier de cours avant de commencer.

08 • ENREGISTRER

Enregistrer sans perdre son travail

Document local

Utilisez Ctrl+S sous Windows ou ⌘+S sur Mac. Lors du premier enregistrement, choisissez le dossier et le nom du fichier.

Pour créer une autre version, utilisez Enregistrer sous ou Enregistrer une copie selon votre version.

OneDrive / SharePoint

Dans Microsoft 365, l’Enregistrement automatique peut sauvegarder les modifications automatiquement lorsque le fichier est stocké dans OneDrive ou SharePoint.

Vérifiez toujours le nom et l’emplacement du fichier.

Bonne pratique : utilisez des noms compréhensibles : TP00_Aouichat_Asma.docx est préférable à Document1.docx.

Créer une version PDF

Le fichier .docx reste le document de travail modifiable. Le .pdf est utile pour remettre ou partager une version dont la mise en page doit rester stable. Conservez le DOCX original lorsque vous exportez en PDF.

09 • ORGANISATION

Fermer, retrouver et rouvrir un document

Assurez-vous que le document est enregistré.
Fermez le document puis Word.
Rouvrez Word et regardez la liste des documents récents.
Si nécessaire, utilisez Ouvrir et parcourez OneDrive ou vos dossiers.
Vérifiez le nom du fichier avant de reprendre votre travail.
Si Word se ferme accidentellement : Word dispose aussi de fonctions de récupération. Pour les fichiers Microsoft 365 stockés dans OneDrive/SharePoint, l’enregistrement automatique et l’historique des versions apportent une protection supplémentaire.

À vous de jouer

Sans reprendre les étapes précédentes, créez un nouveau document nommé Exercice00_Nom_Prenom.docx. Saisissez un titre et deux paragraphes, enregistrez-le dans un dossier Cours Word, fermez Word, retrouvez le fichier, rouvrez-le et ajoutez la date du jour. Terminez en produisant une version PDF.

Afficher les points à vérifier
Auto-évaluation : le nom est correct; le DOCX est dans le bon dossier; le fichier peut être retrouvé après fermeture; la modification est enregistrée; le PDF existe sans remplacer le DOCX.
